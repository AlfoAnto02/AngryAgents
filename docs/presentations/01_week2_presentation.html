Angry Agents

An AI Persona Chat application

Project Overview

A chat application where users interact with AI agents representing realistic personas.

  • DM Messaging: Direct conversations with individual agents
  • Group Chat: Multi-agent conversations on selected topics
  • AI Evaluation: 20 judges assess conversation quality

Persona Sources and Types

Fictional Personas

Sources: Books, movies, TV series

Pros: Consistent behavior patterns

Cons: Limited source material (10k-50k tokens needed)

Real-World Personas

Sources: Podcast transcripts, public figures, intellectuals

Pros: Rich behavior data

Cons: Ideology and behavior more complex to extract

Four Evaluation Dimensions

Persona Identification

Can judges identify message authors?

Individual Fidelity

Does each agent maintain character consistency?

Group Fidelity

Do realistic social dynamics emerge?

Behavioral Fidelity

Does conversation read as human-produced?

Experimentation Pipeline

1. Persona Extraction
2. Chat Simulation (8 agents)
3. Independent Judge Evaluation (Phase 1)
4. Collaborative Judge Deliberation (Phase 2)
5. External Omniscient Evaluation

Persona Extraction: Key Challenges

Shallow vs. Deep

Catchphrases are trivially identifiable but shallow. Underlying patterns enable deeper fidelity.

Source Coverage

Target: 10k–50k tokens per persona for sufficient coverage of style, ideology, and behavior.

Profile Elements

Conversational style, ideological positions, emotional range, humor patterns, social positioning.

Chat Simulation: Balancing Competing Pressures

Agents must balance two competing pressures:

Persona Coherence

Maintain distinctive character traits and behavioral patterns from source material

Conversation Coherence

Stay responsive to recent messages and maintain natural dialogue flow with other agents

Challenge: In long conversations, coherence with recent history tends to dominate, causing agents to drift from their personas.

Judge Specialization

20 judges assigned to different roles to evaluate diverse aspects of conversation quality:

  • Style-focused judges: Evaluate vocabulary, tone, writing patterns
  • Ideology-focused judges: Assess ideological consistency and positioning
  • General judges: Overall evaluation of persona fidelity and authenticity

Phase 1: Independent Judge Evaluation

Each judge completes four independent tasks:

1
Persona Identification

Guess which agent wrote each anonymized message

2
Individual Fidelity

Rate each persona's character consistency (1–5 scale)

3
Group Fidelity

Assess realism of social dynamics and group interactions

4
Behavioral Fidelity

Evaluate if conversation reads as human-produced

Phase 2: Collaborative Judge Deliberation

Judges with high disagreement engage in structured debate to reduce error variance.

Process Structure

  • Identify cases with high variance (high-disagreement persona IDs, wide fidelity ratings)
  • Judges present evidence supporting their positions
  • Structured discussion over 3–5 rounds with tracked variance reduction
  • Judges report confidence levels; track confidence calibration alongside accuracy
  • Generate consensus scores weighted by judge consistency and justification quality

Database Architecture

Core design: chats are organized by topic and agent identities in messages are anonymized through hashing.

Group_chat

Represents a chat session.

Chat_messages

Stores chat messages with anonymized author identity.

Topic

Defines the subject of discussion and groups related chats and agents.

Agents

Stores agent identity, metadata, and optional topic link.

Agent_context

Contains contextual traits and signature phrases for each agent.

Judges

Defines judge roles and evaluation parameters.

Judge_evaluation

Stores each judge’s score for a given chat.

Evaluation Metrics and Statistics

Persona Identification

Accuracy rate vs. 12.5% baseline; binomial confidence intervals; confusion matrix analysis

Individual Fidelity

Median (1–5 scale); interquartile range (IQR) for agreement; variance across judges

Group Fidelity

Gini coefficient (turn distribution); Spearman correlation (sentiment divergence); bootstrap confidence intervals

Phase 2 Deliberation

Variance reduction across rounds (F-tests); convergence rate; confidence calibration curves

External Omniscient Evaluator

An external AI agent with full context: persona profiles, chat messages, and judge evaluations. Assesses the quality of the judging process and identifies areas for improvement.

Key Characteristics

  • Does not influence the evaluation process
  • Evaluates judge performance and identifies blind spots
  • Recommends refinements to evaluation rubrics and procedures
  • Helps validate whether disagreements reflect genuine ambiguity or evaluator error

Failure Modes and Mitigations

Problem Mitigation Strategy
Judge Unfamiliarity Validate judges on known personas; flag low performers
Context Drift Use history truncation techniques (e.g., sliding window, summarization)
Persona Conflation Ensure sufficient source diversity; analyze confusion patterns
Shallow Extraction Enforce 10k–50k token minimum; extract underlying patterns
Overconfidence Track confidence calibration; correlate confidence changes with accuracy
