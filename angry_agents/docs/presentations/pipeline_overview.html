Persona extraction — two-phase pipeline

Source material → structured behavioral fingerprint.

Phase 1 grounds every field in the transcript. Phase 2 adds discriminating model knowledge no transcript can produce.

Phase 1 — Transcript pass
gpt-4o-mini (default)
  • core_style — register, rhythm, sentence shape
  • humor — style, frequency, mechanism
  • worldview — beliefs grounded in the text
  • emotional_tells — pressure, enthusiasm, uncertainty
  • response_patterns — disagreement, deflection, concession
  • relationship_matrix — only real co-speakers
  • annotated_quotes — ≥10 verbatim lines
Phase 2 — Knowledge pass
gpt-4o (per-spec override)
  • favored_words — catchphrases, trademark exclamations
  • structural_patterns — syntactic tics unique to this person
  • do_not_say — ≥5 lines with contradicts annotation
  • No transcript sent — pure model knowledge.
  • Each item must fail the “similar figure” test.
  • Merged into Phase 1 output after both calls.
